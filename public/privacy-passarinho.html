Política de Privacidade — Passarinho CAC

Última atualização: outubro de 2026

1. Coleta de Dados

A extensão Passarinho CAC — Autopreenchimento não coleta, armazena, transmite nem compartilha dados pessoais dos usuários com terceiros.

2. Armazenamento Local

A extensão utiliza o IndexedDB do navegador para armazenar temporariamente os arquivos PDF selecionados pelo usuário. Esses dados ficam armazenados apenas localmente no dispositivo do usuário e não são transmitidos para nenhum servidor externo.

3. Permissões Utilizadas

  • activeTab / scripting: Usadas exclusivamente para preencher automaticamente formulários no sistema TJAM (sistemas.tjam.jus.br) quando o usuário aciona a extensão.
  • storage: Armazena localmente os arquivos PDF selecionados para uso entre sessões.
  • tabs: Identifica a aba ativa do sistema TJAM para executar o preenchimento.
  • host_permissions (sistemas.tjam.jus.br, rwinvestimentos.com.br): Necessário para interagir com o sistema TJAM e consultar dados de clientes cadastrados.

4. Dados de Terceiros

A extensão não vende, aluga, transfere nem compartilha nenhuma informação do usuário com terceiros.
